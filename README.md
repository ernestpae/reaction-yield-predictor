# Reaction Yield Predictor

A Python learning project exploring supervised machine learning for predicting chemical reaction yields from reaction conditions.

## Motivation

I am a chemistry student developing skills at the intersection of machine learning, scientific computing, and molecular modeling. I built this project as part of my effort to understand the fundamentals of applying machine-learning methods to chemical problems.

## Current Implementation

The project:

- Generates a synthetic dataset using reaction temperature, time, and concentration as input features
- Splits the data into training and test sets
- Trains a Linear Regression model
- Trains a Random Forest Regressor for comparison
- Evaluates model performance using Mean Absolute Error (MAE) and R²
- Visualizes predicted versus actual reaction yields

## Tools

- Python
- NumPy
- pandas
- scikit-learn
- matplotlib

## Project Structure

- `src/main.py` — Data generation, model training, evaluation, and visualization
- `data/reaction_data.csv` — Synthetic reaction dataset
